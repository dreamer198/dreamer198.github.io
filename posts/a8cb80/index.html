Mesh 自组网搭建指南

发表于2025-11-17|更新于2025-11-17|无人机开发
|总字数:2.7k|阅读时长:14分钟

无人机集群需要一个不依赖路由器的局域网：每架无人机和地面站都能直接互相通信，某个节点掉线也不影响其他节点。Mesh 自组网正好满足这个需求。本文记录 Mesh 设备的配置流程、IP 规划和连通性验证。

一、Mesh 网络是什么

Mesh 网络（网状网络）中每个节点都可以转发数据。和普通的“所有设备连一台路由器”相比，它有三个特点：

  • 去中心化：不依赖单一接入点；
  • 动态路由：节点之间自动寻找可用的通信路径；
  • 容错：单个节点故障不会让整个网络断开。

本文使用的网络规划如下，所有设备都在 192.168.1.0/24 网段。图中的连线只是示意，实际的转发路径由 Mesh 设备自动选择：

设备 IP 地址
Mesh 设备管理界面（默认） 192.168.1.200
配置用电脑 192.168.1.123
地面站 192.168.1.100
无人机 1 / 2 / 3 192.168.1.101 / 102 / 103

二、配置流程

1. 让电脑进入 Mesh 设备的网段

要访问 Mesh 设备的管理界面，电脑必须和它在同一网段。在系统网络设置中新建一个有线配置：

  • IP 地址：192.168.1.123
  • 子网掩码：255.255.255.0
  • 网关：8.8.8.8

2. 打开管理界面

在浏览器地址栏输入 Mesh 设备的默认地址 192.168.1.200，进入设备管理界面。

3. 切换到 Mesh 组网模式

在管理界面的“网络设置”页面，把网络模式改为“Mesh 组网模式”并保存。每一台 Mesh 设备都要做这一步。

4. 给每个节点分配唯一 IP

在每架无人机上新建网络配置，按上面的规划填写各自的 IP，子网掩码和网关与第 1 步相同。同一网络中 IP 不能重复。

五、要点

配置的关键只有三点：每个设备的 IP 唯一且在同一网段；所有设备都切到 Mesh 组网模式；配置完用 ping 逐个验证。网络打通之后，就可以在此基础上做 ROS 2 多机通信和集群协同。
