Docker 容器内 Fast-Planner 下载、编译与测试

发表于2026-07-13|更新于2026-07-13|无人机开发
|总字数:2k|阅读时长:7分钟

前言

本文是《Docker使用教程》的后续，默认已经按照其中的步骤创建了以下环境：

  • 容器名：ros_noetic
  • 基础镜像：osrf/ros:noetic-desktop-full
  • 宿主机 ~/docker/ros_root 已挂载到容器 /root
  • X11 目录和认证文件已经挂载，容器可以运行 RViz

这里的“全新容器”是指容器已经创建，但还没有下载 Fast-Planner，也没有安装项目依赖。本文不再重复安装 Docker、拉取 ROS 镜像或创建容器，只介绍如何在这个容器中下载、编译和测试 dreamer198/Fast-Planner。

本文默认容器内使用 root 用户，因此 ~ 就是 /root，安装命令不需要 sudo。没有特别说明时，命令都在容器内执行；需要在宿主机执行的命令会单独标出。

Fast-Planner 官方验证过 Ubuntu 20.04 + ROS Noetic。本文只运行项目自带的轻量仿真，不包含 PX4、Gazebo 或真机控制。

等待 RViz 中出现随机障碍物和无人机模型，然后：

  1. 确认 RViz 的 Fixed Frame 为 world。
  2. 点击工具栏中的 2D Nav Goal。
  3. 在地图内没有障碍物的位置点击并拖动，发送一个目标点。

当前仓库的 Kinodynamic Demo 默认使用手动目标模式。目标的 X、Y 坐标来自点击位置，飞行高度默认为 1 m。正常情况下会立即生成 B-spline 轨迹，无人机随后沿轨迹飞向目标。
